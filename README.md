# Official Implementation of the Method "MDIR"

Welcome to the official implementation repository of the paper **"MDIR"**. The code is currently being used for the development of a new project and will be released once it has been organized.
## Project Status

Currently, the paper is under review. We plan to release all training and testing weights as well as the **[CIR](https://pan.quark.cn/s/0831a2f4143b)** dataset upon the paper's official publication. Stay tuned for future updates!
